# 🏥 EISP - App de Vigilancia en Salud Pública

Aplicación web profesional para vigilancia epidemiológica en laboratorios clínicos de Colombia.

## ✨ Características

- 🔐 **Autenticación segura** con múltiples usuarios
- 📊 **Dashboard dinámico** con estadísticas en tiempo real
- 🔍 **Búsqueda avanzada** con filtros por evento
- 🤖 **Asesoramiento IA** basado en Protocolos INS
- 📋 **Definiciones de caso** según normativa oficial
- 🔄 **Algoritmos diagnósticos** paso a paso
- 🧪 **Guía de técnicas** de recolección de muestras
- ↔️ **Referencia y Contrarreferencia** al LSP
- 📱 **Interfaz responsiva** y moderna

## 🚀 Despliegue Rápido

### En GitHub:
```bash
1. Crear repositorio en https://github.com/new
2. Cargar index.html (renombrar desde app-vigilancia-v3-limpia.html)
3. Subir también netlify.toml
```

### En Netlify:
```bash
1. Ve a https://app.netlify.com
2. Click "New site from Git"
3. Conecta tu repositorio GitHub
4. Click "Deploy"
5. ¡Listo en 1-2 minutos!
```

## 🎯 Módulos

| Módulo | Descripción | Filtro |
|--------|-------------|--------|
| Dashboard | Estadísticas en tiempo real | ✅ Por evento |
| Búsqueda Avanzada | Búsqueda múltiple | ✅ Avanzado |
| Definiciones de Caso | Criterios diagnósticos INS | ✅ Por evento |
| Algoritmos Diagnósticos | Flujos paso a paso | ✅ Por evento |
| Tipos de Muestras | Técnicas de recolección | ✅ Por evento |
| Registrar Muestra | Formulario de entrada | ✅ Por evento |
| Referencia al LSP | Procedimiento de envío | ✅ Por evento |
| Contrarreferencia | Resultados del LSP | ✅ Por evento |

## 💾 Almacenamiento

- Datos guardados en **localStorage** (navegador del usuario)
- Cada usuario tiene sus propios datos
- Sincronización automática en tiempo real

## 🎨 Tecnologías

- **HTML5** - Estructura semántica
- **CSS3** - Diseño responsivo con animaciones
- **JavaScript Vanilla** - Sin dependencias
- **Netlify** - Hosting y CI/CD

## 📱 Compatibilidad

- ✅ Chrome, Firefox, Safari, Edge
- ✅ Mobile y Desktop
- ✅ Offline (datos en localStorage)

## 🔒 Seguridad

- Autenticación cliente-side (demo)
- Datos guardados en navegador (no en servidor)
- HTTPS automático por Netlify
- Sin conexión a bases de datos externas
